# Contributing

See [CONTRIBUTING.md](https://github.com/forge-features/forge/blob/main/CONTRIBUTING.md) for detailed contribution guidelines.

## Quick Start

1. Fork and clone the repository
2. Install development dependencies: `pip install -e ".[dev,all]"`
3. Install pre-commit hooks: `pre-commit install`
4. Make your changes
5. Run tests: `make check`
6. Submit a pull request

## Development Commands

```bash
# Run all tests
make test

# Run linting
make lint

# Run type checking
make typecheck

# Run all checks
make check
```
